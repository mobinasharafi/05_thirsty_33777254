## Overview  
Cherry & Chill Liquors is a web application built using **Node.js**, **Express**, and **EJS**.  
It simulates a small liquor shop, allowing users to:  
- Search for drinks by category and name  
- Register as a customer  
- Complete a short customer survey  

The interface is designed to as a clean, consistent, and mildly artistic, reflecting the shop’s identity and my personal preferences for the website.
